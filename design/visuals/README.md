# KMS — ვიზუალური მიმართულება

საიტისთვის შემოთავაზებული სურათები და დიაგრამები. ყველა ფაილი SVG-ია და აწყობილია
პროექტის არსებულ დიზაინ-ტოკენებზე — ფოტოსესია, სტოკის ლიცენზია ან გარე ბიბლიოთეკა არსად სჭირდება.

## რატომ

მთავარი გვერდი 15 087 პიქსელია და მასზე არც ერთი რეალური გამოსახულება ან დიაგრამა არ დევს:
მხოლოდ 20 პიქსელიანი იკონები, თეთრი ბარათები, ერთი თითქმის უხილავი ჰერო-გრაფიკა
(ხაზის გამჭვირვალობა `0.14`) და ერთი ცარიელი ნაცრისფერი ბლოკი, სადაც სურათი არასდროს ჩასმულა.

## გამოყენება

SVG-ები დამოუკიდებელია — შრიფტის სტეკი თითოეულში `<style>`-ითაა ჩაშენებული,
ამიტომ `<img>`-ითაც სწორად გამოისახება:

```tsx
<img src="/visuals/hero-proposed.svg" alt="" aria-hidden width={640} height={540} />
```

თუ ანიმაცია და თემის მიხედვით ფერის ცვლა გჭირდებათ, ჩასვით ინლაინ, React-კომპონენტად.
`<img>`-ის შემთხვევაში `<animate>` მუშაობს, მაგრამ CSS გარედან ვეღარ სწვდება.

## ანიმაცია და `prefers-reduced-motion`

მოძრავი ელემენტები მონიშნულია `class="pulse"` და `class="blink"` კლასებით.
ინლაინ ჩასმისას დაამატეთ:

```css
@media (prefers-reduced-motion: reduce) {
  .pulse, .blink { display: none; }
}
```
