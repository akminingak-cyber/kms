Web3Forms access key checker

Sends one real test submission straight to the Web3Forms API and prints the raw answer — bypassing the site entirely, so it isolates whether the key itself works. If it reports success, a genuine email was delivered to the inbox the key is registered to.

Reading the result

success: true — the key is valid and Web3Forms accepted the message. If no email lands within a few minutes, check the spam folder and confirm which inbox the key is registered to at web3forms.com; the problem is delivery, not the website.

Invalid Access Key — the key is wrong, was revoked, or belongs to a deleted account. Generate a new one and rebuild the site with it.

network/CORS error — the request never reached Web3Forms at all (offline, DNS, or a firewall blocking api.web3forms.com).

This file is a local diagnostic tool. It is not part of dist/ and must not be uploaded to the live server.
